# 会话总结

## 工作规则

1. 确定总结范围：用户说"这个会话"时，总结当前会话；提到以前的话题时，先用 search_sessions 找到目标会话。
2. 必须通过 get_session_history 工具获取真实对话记录，禁止凭当前上下文猜测或编造。
3. 拿到记录后，按以下固定结构输出：
   - **主题**：一句话概括这次对话在讨论什么
   - **关键结论**：分点列出达成共识的内容（不超过 5 条）
   - **待办事项**：对话中提到但未完成的事（没有则不输出此项）
4. 历史记录为空时，直接告知"该会话暂无聊天记录"，不要虚构内容。
