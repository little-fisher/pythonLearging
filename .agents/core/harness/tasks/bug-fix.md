# 任务：Bug 修复

当用户描述行为损坏、残留状态、布局漂移、渲染错误或运行时失败时使用。

## 先读

1. `.agents/project/charter.md`
2. 失败功能的最近实现面
3. 本地控制路径仍不清楚时，再读相关项目领域文档

## 执行原则

- 从最具体的失败锚点开始。
- 先形成一个局部根因假设。
- 只阅读足够定位控制路径的附近代码。
- 在 owning 层修复根因，避免下游补丁。
- 第一处实质修改后尽快做窄验证。

## 检查清单

- 哪段代码直接控制失败行为？
- 是否能在所属抽象内修复，而不是补在下游？
- 是否保留现有模式和状态边界？
- 是否有针对改动切片的验证？
- 是否避免了无关清理和重构？
