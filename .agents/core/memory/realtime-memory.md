# 实时记忆

非简单任务使用 `.agents/project/memory/current/` 作为当前任务状态板。

## 文件职责

- `context.md`：影响后续步骤的稳定事实和实现锚点。
- `progress.md`：当前目标、已完成项、待处理项、验证状态和停止点。
- `bugs.md`：确认问题、风险、失败尝试和人工确认项。

## 更新时机

- 非简单任务开始时。
- 已确认任务路由、项目文档和 CodeGraph 入口时。
- 选定实现方案时。
- 失败尝试或阻塞改变计划时。
- 验证通过或失败时。
- 任务即将结束或暂停时。

## 写入规则

- 写当前有效事实，不写命令流水账。
- 假设必须标注为假设。
- 过期任务细节及时压缩或删除。
- 不存密钥、账号和敏感信息。
- 不复制长规则，只链接或点名权威文档。

## 结束前压缩

最终回复前，把 `current/` 文件压缩到能回答：

- 现在什么是真的。
- 已完成什么。
- 还存在什么风险。
- 下一个 Agent 接手需要知道什么。
