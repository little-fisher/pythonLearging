# 证据报告

任务完成汇报可按以下结构组织，重点说明“改了什么、验证了什么、还有什么没验证”。

## 必要字段

- 改动范围：涉及的文件和模块。
- 已验证：通过的命令、路由、交互或数据检查。
- 未验证：没有执行的检查及原因。
- 风险：剩余不确定性、人工确认项或工具限制。
- 构建状态：是否运行 build；若未运行，说明是否遵循了不默认重型打包的规则。
- 契约状态：如创建任务契约，说明必需成功标准和 Evaluator 结论。

## 示例

```md
已验证：
- Playwright 打开 `/storm-surge`，按钮可见并可点击。
- Node 解析 `src/assets/js/.../data.json` 成功。
- CodeGraph 确认新增图层接入清理链路。

未验证：
- 未运行 `npm run build`，遵循项目规则不默认执行重型打包。

风险：
- 地图 canvas 内风险区划形状需要人工对照参考图确认。
```
